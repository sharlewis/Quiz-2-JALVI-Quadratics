Formula Cheat Sheet

The exact tools you need for this test.

STANDARD FORM
f(x) = ax² + bx + c
Vertex x = −b/(2a), then plug in for y. c is the y-intercept. a > 0 opens up, a < 0 opens down.
VERTEX FORM ⭐
y = a(x − h)² + k
Vertex is (h, k) — h flips sign: (x − 3) → h = 3, (x + 4) → h = −4. Axis of symmetry x = h.
FACTORED FORM
y = a(x − p)(x − q)
Zeros (x-intercepts) at x = p and x = q. Axis of symmetry x = (p + q)/2.
MAX or MIN
a > 0 → minimum · a < 0 → maximum
The value is k (the vertex's y-value).
DOMAIN & RANGE
Domain: (−∞, ∞)
Range: [k, ∞) if it opens up (min) · (−∞, k] if it opens down (max).
ZEROS ⭐ & y-INTERCEPT
Zeros: set y = 0, factor, solve
y-intercept: plug in x = 0 (equals c in standard form).
